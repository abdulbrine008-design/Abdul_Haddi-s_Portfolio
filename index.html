Featured project

Multi-class classification on a large real-world dataset

python · pandas · scikit-learn · random forest
Problem
Predict a three-category outcome from a messy, 227,980-row dataset with 72 columns, several of them high-cardinality (up to ~2,000 unique values) and one class making up less than 1% of the data.
Method
Built a full preprocessing pipeline — missing-value handling, high-cardinality and ordinal/nominal encoding, feature scaling — then compared Logistic Regression against Random Forest, checking feature importances along the way to rule out leaking columns before trusting any result.
Result
87.5% test accuracy and 84.2% balanced accuracy with Random Forest, with precision and recall reviewed per class rather than relying on overall accuracy alone.
